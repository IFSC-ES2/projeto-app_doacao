# ADR-0001 – Stack do projeto

## Status
Aceita

## Contexto
Precisamos escolher tecnologias que sejam fáceis de usar em equipe e que permitam desenvolver o sistema ao longo do semestre.

## Decisão
Vamos usar:

- Backend: Java com Spring Boot  
- Frontend: React (Vite)  
- Banco de dados: PostgreSQL (produção) e H2 (desenvolvimento)

## Consequências

### Positivas
- Boa organização do código  
- Tecnologias bem conhecidas  
- Fácil manutenção  

### Negativas
- Configuração inicial mais trabalhosa  
- Curva de aprendizado para alguns membros
