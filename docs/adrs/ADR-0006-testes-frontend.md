# ADR-0006 – Testes do frontend com Vitest

## Status
Aceita

## Contexto
O frontend React precisa de testes automatizados para evitar que alterações quebrem funcionalidades existentes.

## Decisão
Usar Vitest + React Testing Library para testar o frontend.

## Consequências
### Positivas
- Integração nativa com Vite, sem configuração extra
- Feedback rápido durante o desenvolvimento

### Negativas
- Curva de aprendizado para membros sem experiência com testes de frontend
