# ADR-0002 – Tipo de aplicação

## Status
Aceita

## Contexto
O sistema será usado por pessoas da ONG para controlar doações e estoque.

## Decisão
O sistema será:

- Uma aplicação web  
- Usada pelo navegador  
- Com frontend e backend separados  

Não haverá aplicação mobile neste projeto.

## Alternativas consideradas
- Aplicação desktop  


## Consequências

### Positivas
- Fácil acesso (não precisa instalar)  
- Pode ser usado em qualquer computador  

### Negativas
- Precisa de internet
