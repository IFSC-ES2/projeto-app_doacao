# ADR-0003 – Arquitetura do sistema

## Status
Aceita

## Contexto
O projeto precisa ser organizado para facilitar o desenvolvimento em equipe.

## Decisão
Vamos usar arquitetura em camadas:

- Controller  
- Service  
- Repository  
- Model  

## Alternativas consideradas
- Código sem separação  
- Arquitetura mais complexa  

## Consequências

### Positivas
- Código mais organizado  
- Mais fácil de entender e manter  

### Negativas
- Mais arquivos no projeto
