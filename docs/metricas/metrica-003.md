# Taxa de Aprovação nos Testes (Test Pass Rate)

- **Data do acompanhamento:** ___/___/____
- **Valor coletado:** ______ %

## Classificação
Produto

## Objetivo
Ver se as partes do sistema que já foram feitas realmente funcionam.

## Definição / Fórmula
(funcionalidades funcionando / funcionalidades feitas) × 100

## Fonte dos dados
Testes feitos pela equipe.

## Frequência
Final de cada sprint.

## Responsável
Haydeé Murara

## Interpretação
Se chegar perto de 100%, quer dizer que quase tudo que foi feito está funcionando.
