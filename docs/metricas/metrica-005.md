# Taxa de Conclusão da Sprint (Sprint Completion Rate)

- **Data do acompanhamento:** 08/06/2026
- **Valor coletado:** 100%

## Classificação
Processo

## Objetivo
Ver se a equipe conseguiu fazer o que tinha planejado.

## Definição / Fórmula
(tarefas terminadas / tarefas planejadas) × 100

## Fonte dos dados
Board da sprint.

## Frequência
Final de cada sprint.

## Responsável
Lucas Gabriel

## Interpretação
Quanto mais perto de 100%, melhor foi o planejamento.
