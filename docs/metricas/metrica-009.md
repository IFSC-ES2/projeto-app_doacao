# Taxa de Tarefas Atrasadas (Overdue Task Rate)

- **Data do acompanhamento:** 28/05/2026
- **Valor coletado:** 0%

## Classificação
Projeto

## Objetivo
Ver quantas tarefas passaram do prazo.

## Definição / Fórmula
(tarefas atrasadas / total de tarefas) × 100

## Fonte dos dados
Datas das issues.

## Frequência
Final de cada sprint.

## Responsável
Haydeé Murara

## Interpretação
Quanto maior esse número, mais atrasado está o projeto.
